# Проверка на втором компьютере

Проводите на AMD-ноутбуке с фактическим масштабом экрана. Не включайте все дополнительные ядра для обычной работы: это отдельная проверка максимального набора.

- [ ] Чистый clone: `dotnet restore`, Release с `-warnaserror`, `dotnet test`; нет ошибок/предупреждений.
- [ ] Первый запуск, обнаружение AMD, встроенной/дискретной видеокарты, ОЗУ, накопителей и доступных вентиляторов.
- [ ] С установленным PawnIO и административными правами сравнить температуру/частоту/мощность с диагностикой и доверенной утилитой производителя. Отсутствующие датчики показывают `—`, а не ложный ноль.
- [ ] Только процессор; процессор и ядра; только видеокарта; все основные показатели; много вторичных. Подробности строго ниже своего устройства, нет наложений, переноса по текущему числу и прыгающих размеров.
- [ ] Изменение флажков сразу отражается в открытом виджете.
- [ ] Перемещение за пустые места между строками и справа; закрепление запрещает перемещение и пропускает щелчки в нижнее окно.
- [ ] Встроенная палитра: несколько произвольных оттенков, отмена/подтверждение, изменение цвета сразу. Нет готовых пресетов.
- [ ] Прозрачность меняет буквы/обводку; размеры 12/14/20 читаются, фона и рамки нет.
- [ ] Светлая/тёмная тема: подписи и значения, включая «об/мин», читаются; цвет виджета не сбрасывается. Полоса прокрутки настроек не закрывает числа.
- [ ] Экран около 2.5K, масштабы Windows 100/125/150 %, минимальный размер окна; при наличии второго экрана — перенос между мониторами. Выйти/перезапустить после смены масштаба.
- [ ] Горячие клавиши: включение/скрытие и закрепление; конфликт не теряет прежнюю комбинацию.
- [ ] Перезапуск: флажки, тема, цвет, прозрачность, размер, обводка, горячие клавиши, положение и закрепление восстановились. Виджет включается вручную.
- [ ] Сон/пробуждение, питание от батареи/сети, смена активной видеокарты, подключение монитора; нет зависания и выдуманных показаний. Изменение состава железа может потребовать перезапуска.
- [ ] Длительная работа 30–60 минут: память/потоки не растут непрерывно, интерфейс отвечает. «Выход» в трее удаляет значок и завершает процесс.
- [ ] Виджет в браузере, рабочем ПО, оконной/безрамочной игре. Эксклюзивный полноэкранный режим не гарантирован.

Не вызывайте перегрев специально для проверки предупреждения. Пороговые переходы, пропавшие значения и гистерезис покрыты моделируемыми тестами; физические пределы зависят от модели.

Если есть ошибка, запишите модель устройства, версию Windows, масштаб и действия для воспроизведения. Отчёт диагностики сначала проверьте на личные данные и храните локально; не отправляйте автоматически в Git. Конкретные AMD/NVIDIA/Intel модели считаются проверенными только после фактического испытания.
