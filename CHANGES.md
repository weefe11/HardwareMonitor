# Результаты проверки v1.0.0

Проверка завершена 2026-10-07. На релизном проходе исходный код не изменялся: обновлены сведения об оборудовании, документация и manifest. Доработка AMD SMT из коммита `7a029a6` проверена ревью и тестами; дополнительных воспроизведённых ошибок, требующих изменения рабочей логики, не обнаружено.

## Автоматические проверки

- Clean → restore → Release build с `-warnaserror`: 0 ошибок, 0 предупреждений.
- NUnit: 13 сценариев, все прошли, без пропусков; сохранены 155 внутренних утверждений логики/WPF, добавлены проверки остановки опроса и AMD SMT.
- Покрыты форматирование, null/NaN/аномалии, приоритет температуры Intel/AMD, рекурсивное оборудование, группы и подробности виджета, много ядер, сохранение/миграция, HSV/RGB, реальные элементы цвета/прозрачности, предупреждения, горячие клавиши и отмена опроса.
- На обеих машинах дополнительно прошли 7 аппаратных проверок запуска; на ноутбуке три снимка административного опроса без ошибок.
- Проверка чистой копии отслеживаемых исходников выполнена при первоначальной подготовке; ноутбук собирал проект из Git clone без переноса локальных bin/obj.
- GitHub Actions: Windows, restore → Release с предупреждениями как ошибками → NUnit. [Запуск для аппаратного исправления 7a029a6](https://github.com/weefe11/HardwareMonitor/actions/runs/37571297276) завершился успешно. Для каждого последующего коммита проверяйте его отдельный результат в Actions.

## Физические конфигурации

Intel Core i3-14100F / NVIDIA GeForce RTX 5060 и AMD Ryzen 7 7840HS / AMD Radeon 780M Graphics. Обе системы использовали PawnIO 2.2.0; подтверждены реальные датчики CPU/GPU/ОЗУ/накопителя, виджет, палитра, прозрачность, горячие клавиши и восстановление настроек. На ноутбуке — дисплей 2560 × 1600, ручные масштабы 100/125/150 %, перемещение/фиксация и исправленная схема 8 ядер × 2 потока.

Сведения извлечены из аппаратных отчётов и итоговых ручных подтверждений владельца; промежуточные записи о незавершённых действиях не являются итоговым статусом. [Полная сводка с границами доказательств](docs/TESTED_HARDWARE.md).

## Оставшиеся ограничения

На Radeon 780M этой машины отсутствуют температура/мощность GPU, плата и вентиляторы; отсутствующие значения не выдумываются. Не заявляются универсальная совместимость, смешанный DPI, рекомендуемый масштаб ноутбука или работа во всех эксклюзивных полноэкранных играх. Короткие проверки ресурсов не заменяют многочасового испытания. Предупреждения — ориентиры внимания к охлаждению, а не диагноз.
