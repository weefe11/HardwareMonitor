# Мониторинг ПК

[![Сборка и тесты Windows](https://github.com/weefe11/HardwareMonitor/actions/workflows/windows-ci.yml/badge.svg)](https://github.com/weefe11/HardwareMonitor/actions/workflows/windows-ci.yml)

Русскоязычное приложение для наблюдения за состоянием компьютера во время игры или работы. Выберите показатели флажками и включите компактный текстовый виджет поверх окон — без видимой фоновой панели и рамки.

## Возможности

- Главная строка каждого устройства и выбранные подробности строго под ней; постоянные колонки и моноширинные числа без переносов при обновлении.
- Полная палитра произвольного цвета, прозрачность букв и обводки, размер текста 12–20. Изменения сразу применяются к открытому виджету.
- Перемещение за всю внутреннюю область, закрепление с пропуском щелчков, глобальные горячие клавиши и работа в трее.
- Автосохранение выбора и настроек, минимум/максимум за сеанс, диагностика исходных датчиков, светлая и тёмная тема.
- Небольшие температурные индикаторы с защитой от мерцания. Это ориентиры для внимания к охлаждению, а не диагноз неисправности.

## Показатели

| Устройство | При наличии датчиков |
| --- | --- |
| Процессор | Температура, общая загрузка, частота, мощность, подробности ядер/потоков |
| Видеокарта | Температура, загрузка, частоты ядра/памяти, мощность, занятая видеопамять, дополнительные температуры и вентиляторы |
| Оперативная память | Использование, занятый и доступный объём |
| Накопители | Температура, заполненность и свободный объём |
| Плата | Обороты доступных вентиляторов |

Доступность зависит от модели, прошивки и драйверов. `—` означает отсутствие данных или невозможное значение; настоящий ноль сохраняется. Поддержка конкретных двух систем не означает поддержку всех устройств Intel/AMD/NVIDIA.

## Требования и запуск готовой версии

Windows 10/11 x64 и .NET Desktop Runtime 8 x64. Для низкоуровневых датчиков процессора/платы может понадобиться отдельно установленный подписанный [PawnIO](https://pawnio.eu/). NuGet не устанавливает системный драйвер; после его установки перезапустите приложение.

Готовые пакеты распространяются через [GitHub Releases](https://github.com/weefe11/HardwareMonitor/releases). Распакуйте весь ZIP и запустите `HardwareMonitor.exe`: манифест запрашивает административные права через UAC. DLL рядом с EXE необходимы; пакет не содержит .NET Runtime и PawnIO.

1. Отметьте нужные показатели.
2. В «Отображение и управление» нажмите образец цвета и выберите оттенок в палитре.
3. При желании измените прозрачность/размер текста и включите «Показать виджет».
4. Для перемещения снимите «Закрепить».

Закрытие окна сворачивает приложение в трей; «Выход» завершает опрос и освобождает ресурсы. Настройки сохраняются в `%LOCALAPPDATA%/HardwareMonitor/settings.json`; виджет после запуска включается вручную. Прозрачность относится к буквам/обводке. Для захвата мыши в пустых местах откреплённого виджета используется невидимая служебная область с альфа-каналом 1/255.

## Сборка из исходников

Нужны Windows, Git и .NET SDK 8 или новее.

```powershell
git clone https://github.com/weefe11/HardwareMonitor.git
cd HardwareMonitor
dotnet restore
dotnet build -c Release --no-restore -warnaserror
& ./HardwareMonitor/bin/Release/net8.0-windows/HardwareMonitor.exe
```

Стек: C#, .NET 8, WPF, WPF-UI, CommunityToolkit.Mvvm, LibreHardwareMonitorLib 0.9.6. Палитра и обводка реализованы средствами WPF; аппаратный опрос выполняется в отдельном последовательном цикле.

## Тестирование и CI

```powershell
dotnet test -c Release --no-build --no-restore
```

NUnit выполняет **13 сценариев**, включая сохранённые 155 внутренних проверок логики/WPF. Проверяются форматирование и недоступные значения, моделируемые Intel/AMD-датчики и приоритет температур, рекурсивное обновление, блоки виджета/много ядер, AMD SMT, настройки/миграция, HSV/RGB, цвет/прозрачность, предупреждения, горячие клавиши и отмена опроса. Моделируемые данные не заменяют испытание конкретного оборудования.

[GitHub Actions](.github/workflows/windows-ci.yml) на Windows выполняет `restore → Release build -warnaserror → NUnit tests` при push и pull request. Фактическое состояние запуска отображается в Actions; успешная локальная сборка сама по себе не подтверждает результат CI.

## Проверенное оборудование

Приложение прошло ручную проверку на двух физических конфигурациях; автоматически дополнительно проверяются моделируемые наборы датчиков.

| Конфигурация | Подтверждённые сведения |
| --- | --- |
| Основной ПК | Intel Core i3-14100F, NVIDIA GeForce RTX 5060, Windows, PawnIO 2.2.0; датчики процессора/видеокарты/ОЗУ/накопителя и платы |
| Ноутбук | AMD Ryzen 7 7840HS, AMD Radeon 780M Graphics, Windows x64 (сборка 26100), PawnIO 2.2.0; экран 2560 × 1600, ручная проверка масштабов 100/125/150 % |

На обеих системах проверены виджет, палитра, прозрачность, горячие клавиши и восстановление настроек. На ноутбуке подтверждены 8 физических ядер/16 потоков, перемещение за всю область и фиксация. Температура/мощность GPU, вентиляторы и плата на этом ноутбуке недоступны. [Подробности и границы проверки](docs/TESTED_HARDWARE.md).

## Известные ограничения

- Набор датчиков зависит от оборудования и доступа к драйверу. Нет гарантии для всех моделей Intel/AMD/NVIDIA.
- Эксклюзивный полноэкранный режим игр не гарантируется; обычные и безрамочные окна поддерживаются.
- Изменение выбора меняет состав и размер виджета; большое число выбранных ядер увеличивает высоту. Смешанный DPI нескольких мониторов и рекомендуемый масштаб ноутбука отдельно не подтверждены.
- Нет измерения времени кадров. Непроверенные напряжения и активность накопителей остаются в диагностике; частота видеопамяти показывается без пересчёта в скорость передачи данных.
